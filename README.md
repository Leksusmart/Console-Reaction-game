# Проверка реакции

Добро пожаловать в мини-игру "Проверка реакции"! Эта игра предназначена для проверки вашей реакции на визуальные сигналы.

## Описание игры

В данной игре вам нужно как можно быстрее нажать на любую клавишу после появления зелёного сигнала.

## Как играть

1. Запустите программу.
2. Следуйте инструкциям на экране.
3. После появления зелёного сигнала, нажмите любую клавишу как можно быстрее.
4. После каждой игры вам будет предложено продолжить или выйти.

## Установка

Скачайте `Reaction-Game.exe` из последнего релиза

## Используемые технологии

- C++
- Windows API
- Chrono для измерения времени реакции

## Лицензия

Эта игра предоставляется "как есть" без каких-либо гарантий. Используйте на свой страх и риск.
